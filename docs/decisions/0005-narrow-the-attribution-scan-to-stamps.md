# Narrow the attribution scan to stamps, not to words

## Context

The repository legitimately talks about model providers. `src/shared/provider.ts`
implements Anthropic and OpenAI-compatible clients; the README explains what a
model call costs; the architecture diagram has a node labelled for the planner.

A first attempt at an attribution check searched for AI tool names anywhere in
a file. It flagged the provider module, the word "AI" in the copy, and a robot
emoji in a diagram.

## Decision

Match **stamp-shaped** patterns only: line-anchored banners, generated-by
headers, co-authored trailers, and the same shapes in commit messages and
authorship.

## Rationale

The point of the check is to stop an attribution that a reader would mistake
for the author's own work. "This file was generated by X" is such an
attribution. "The `claude` provider" is the name of a dependency.

A scanner that flags both is a scanner that gets disabled, and a disabled
scanner catches nothing. Narrowing the pattern keeps it specific enough that it
stays switched on — and the gate step for it only means something if the gate
is green often enough that people read it.

The check still fails on a real banner, and that failure was watched before the
check was trusted.
